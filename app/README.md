# MVC PHP Native - Data Produk

Aplikasi CRUD sederhana untuk mengelola data produk menggunakan PHP Native dengan pola Model-View-Controller (MVC).

## Kebutuhan
- PHP 8.0 atau lebih baru
- MySQL/MariaDB
- Web server lokal (XAMPP/Laragon)
- Git

## Struktur MVC
- `app/models/` — akses dan operasi data
- `app/controllers/` — alur request
- `app/views/` — tampilan HTML
- `config/` — konfigurasi database
- `database/` — skema SQL
- `public/` — entry point aplikasi
